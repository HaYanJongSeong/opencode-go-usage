# left / Left / 사용량

Termux에서 `left`, `Left`, `사용량`으로 Go·Codex의 남은 사용량과 리셋까지 남은 시간을 확인한다. 세 이름으로 실행하는 프로그램은 같다.

OpenCode 일반 입력창에서는 `!left`, `!Left`, `!사용량` 중 하나를 입력한다. 이미 셸 모드라면 느낌표 없이 명령 이름만 입력한다. Termux에서도 느낌표는 붙이지 않는다.

모델은 호출하지 않고 기존 `go-codex-quota.read` RPC로 조회한다. 기존 `/left`·`/사용량` 슬래시 명령과는 별개다. Codex 수치는 ChatGPT 전체 사용량이 아니라 Codex 한도다.

각 잔여율 옆에 리셋까지 남은 일·시간을 표시하고, 하루 이내이면 시간·분을 표시한다. API가 리셋 시각을 제공하지 않으면 `리셋 시각 미제공`, 조회 시각에 이미 도달했으면 `리셋 시각 도달`로 표시한다. 임의의 리셋 시각을 추정하지 않는다.

## @ 문맥 첨부

`left`를 실행할 때마다 `~/left-snapshot.md`도 갱신된다. 의도한 사용 순서는 셸에서 `left` 실행 후 일반 입력 모드에서 `@left-snapshot.md` 검색·파일 선택이다.

현재 폰의 OpenCode v2.0.22에서는 웹 `@`와 동일한 파일 검색 API 요청이 HTTP 500을 반환한다(2026-10-19 검증). 스냅샷 생성과 파일 읽기 API의 본문 일치는 확인했지만, `@` 검색·선택 연결은 아직 완료하지 못했다. UI·서버·전역 설정은 수정하지 않았다.

`@` 첨부 자체는 재조회나 모델 실행을 하지 않는다. 마지막 조회 시각이 적힌 스냅샷이므로 최신 자료가 필요하면 먼저 셸에서 `left`를 실행한다. 첨부 후 일반 질문을 전송하면 그때 모델 입력에 포함된다.

조회·파싱 실패 또는 Ctrl+C 취소 시에는 옛 수치를 지우고 시각과 오류로 스냅샷을 교체한다. 파일 저장이 실패하면 셸 결과는 유지하고 경고와 종료 코드 1을 반환한다. Ctrl+C 취소의 종료 코드는 130이다. 실행할 때 갱신되는 스냅샷은 설정동기화 대상에서 제외한다.

## 조회 경로와 보안

실행 중인 로컬 OpenCode 서버에는 CLI를 매번 기동하지 않고 기존 `go-codex-quota.read` RPC로 직접 연결한다. 응답을 캐시하거나 제공자 조회를 생략하지 않는다.

서비스 등록파일이 일반파일·동일 UID·0600인지 확인하고, 숫자 loopback URL만 허용한다. `/api/info`의 PID·버전이 등록과 일치해야 사용량 RPC를 한 번 호출한다. 로컬 서버 등록 암호는 메모리에서만 기존 인증에 재사용하며 출력·문서·설정백업에 저장하지 않는다. 제공자의 로그인 쿠키·API 키는 직접 읽지 않는다. 프록시·리디렉션으로 인증을 외부 전송하지 않는다.

등록이 없거나 안전하게 지원하지 못하는 상태는 기존 OpenCode CLI 경로를 사용한다. 불신 등록파일·외부 URL은 CLI로 우회하지 않고 실패한다. 기존 CLI 경로는 서버가 꺼져 있으면 자동 시작할 수 있다. 직접 연결과 CLI를 합한 조회 상한은 30초이고, RPC 전송 후 오류에는 재시도하지 않는다.

조회 실패 시 과거 값이나 추정치를 표시하지 않는다. 한 제공자라도 실패하면 확인 가능한 결과와 오류를 표시하고 종료 코드 1을 반환한다.

## 설치와 복원

GitHub 저장소에서 설치할 때는 저장소 폴더에서 실행한다.

```sh
bash scripts/install-left.sh
```

명령 이름은 설치 스크립트 옆의 `left.py`를 가리키는 심볼릭 링크다. 저장소에서 설치했다면 그 폴더를 옮기거나 지우지 않는다. 같은 링크에는 다시 설치해도 되지만, 이름이 겹치는 다른 파일·링크·디렉터리는 덮어쓰지 않는다.

Termux 설정백업에서 `scripts/`를 복원했다면 다음 명령으로 세 이름을 다시 연결한다. `$PREFIX/bin`의 링크 자체는 설정백업에 넣지 않는다.

```sh
bash ~/.config/opencode/scripts/install-left.sh
```

설치와 재설치에는 서버 재시작이나 웹 UI 수정이 필요하지 않다. 기존 `/left`·`/사용량`은 별도의 슬래시 명령으로 남는다.
